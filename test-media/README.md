# Test Media Files

This directory contains sample media files for testing the Provenance Playground app.

## File Categories

### Real/Authentic Content
- `real_photo1.jpg` - Authentic photograph
- `sunset_real.jpg` - Real sunset photo
- `street_photo.jpg` - Authentic street photography

### AI-Generated Content
- `ai_photo1.jpg` - AI-generated image
- `ai_artwork.jpg` - AI-created digital art
- `ai_landscape.jpg` - AI-generated landscape

### Sample Files
- `sample_photo.jpg` - General test image

## Usage

These files are used by:
1. The quiz system for comparison challenges
2. The social feed simulation
3. Manual testing of the upload analyzer

## Note

In a production environment, you would replace these placeholder files with actual media samples. The current implementation uses mock detection algorithms that can be enhanced with real C2PA SDK integration and AI detection models.
